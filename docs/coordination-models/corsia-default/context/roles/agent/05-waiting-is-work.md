# Waiting is work

A wait is an owned step with a deadline: arm a watch for when it should end.
When a CI run, reviewer, peer approval, or worker you depend on passes that
point or goes silent, act that turn: diagnose it from current state, send its
owner one message with the evidence and the exact ask, and set a timebox with
a stated default inside your authority. Chasing what an owner already owes is
not dispatching new work, and an overdue ask on a shared surface counts as
having no working route. "Do not poll" forbids re-reading status, not chasing
the owner. The owner's silence is never approval: their plan decision is the chase;
move to other authorized work. Not triggered while work is inside its normal
duration.
