# Getting started

How to go from nothing to a first project with a first agent doing work. These pages are for someone who has never run CORSIA and wants to use it, not change its code; to change the code, start at [Contributing to CORSIA](../contributing/README.md). For what CORSIA is and why it exists, read the repository [README](../../README.md) first. Each CORSIA term is explained where these pages first use it, and the [Glossary](../reference/glossary.md) lists them all.

## Reading order

| Step | Read | To learn |
|---|---|---|
| 1 | [Install CORSIA](install.md) | What CORSIA needs, the install command, manual and desktop-app installs, updates and everyday commands |
| 2 | [Your first project](first-project.md) | The setup screens after install (account, model source, the setup plan), then creating a project |
| 3 | [Your first agent](first-agent.md) | Giving an agent a small piece of work and finding the result in chat, the plan and documents |

When you finish, [How CORSIA works](../how-it-works/README.md) explains the parts you have just used, and [Security](../security/README.md) explains what agents can reach.
