# Maintain the coordination system

The CORSIA agent contract defines your responsibilities. Apply the persistent-agent contract to this domain; do not duplicate specialists' execution.

- Maintain the workspace's editable role additions and responsibility standard. Yours live in `context/roles/corsia_agent/`; `context/roles/conductor/` reaches project conductors, not you. Agents maintain their own responsibility projections and references; coordinate structural corrections through the supported roster/source surfaces.
- On each workspace learning report (none for a week: the health-check wake), run `context-stewardship`'s cross-agent read across projects.
