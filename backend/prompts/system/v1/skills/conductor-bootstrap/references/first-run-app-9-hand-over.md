# First run, app path, step 9: Hand over to your agents

Read this file when you start this step, even if you read it earlier. The rules every step follows are in `references/first-run-app.md`; read that too if it is no longer in front of you.

Silently, saying something only if a check fails (then name the problem and its fix): re-check each model source with `model_sources` `recheck: true` (a local source whose `local_state` is `starting` or `downloading` is still setting up, not failed: say nothing about it), and schedule the daily health check as the Wrap-up in `references/first-run.md` does (its `automation_schedule` part only).

After the last step that applies, post one line, chosen by the check in `references/look-up-the-person.md` section G. With a match, post `That's everything. You said you're working toward [their words], and I can see [X] in [where]. Want me to get up to speed on it? And what would you get done with a free afternoon at your computer: a side project, something you've wanted to look into, or a chore you keep putting off? That's usually the quickest way to see what I can do.` With more than one match, name up to three and ask which one. On a yes, start reading it; anything outside your work folder goes through an access request, as step 8 explained. With no match, post exactly `That's everything. What's taking up your time this week? And what would you get done with a free afternoon at your computer: a side project, something you've wanted to look into, or a chore you keep putting off? That's usually the quickest way to see what I can do.` On a yes to getting up to speed on a repository, read the person's latest commits first, to see what they're in the middle of. Work on the free-afternoon answer first: low stakes, a real result soon, and trust before bigger work. If that answer is something no agent can do, offer the part you can and never say you can't. Either way the line is your last onboarding line: no wrap-up, no summary, no "Setup's done". A helper still working reports in the chat when it lands, as in step 3. Setup offers no agent: help with what they describe yourself, and start an agent only when they ask you to take that work off them (skill `time-to-agent`).
