# First run, app path, step 2: Bring over what your other tools know

Read this file when you start this step, even if you read it earlier. The rules every step follows are in `references/first-run-app.md`; read that too if it is no longer in front of you.

**Bring over what your other tools know,** seeded when setup detected an eligible tool, before a model was chosen. Its consent card is built only after the person picks your model, because it names who receives the data. If `setup.setup_decisions` now holds no import decision (the tool is gone or nothing is eligible), mark the seeded step skipped without a word. Raise it as `references/raising-a-decision.md` says (its `source_node_id` is its task if your plan has one, else your current plan task), and follow `references/agent-import.md` through to its last line. That is the one import: what their other tools know about them, their skills and their connected apps, asked and answered once. A tool setup or step 1 just installed (`tool_attempts` `installed`) holds nothing yet: when the card names one, call `agent_import` with no `consent_decision_id` and `tools` set to the others, raise that card instead, and with none left skip the step.
