# First run, app path, step 6: Email and calendar

Read this file when you start this step, even if you read it earlier. The rules every step follows are in `references/first-run-app.md`; read that too if it is no longer in front of you.

**Email and calendar.** Skipped when `email_calendar_ready`; a connected account already has both mail and calendar. Post: `Which email do you use: Gmail (a work Gmail counts), Outlook, or something else?` If they're not sure, ask what they open to read it. Outlook covers Outlook, Hotmail, Live and Microsoft 365.
- **Outlook, both, or something else:** first write one line in the workspace's `context/50-USER-PROFILE.md`, `- **Email app:** <Outlook | Other> — <what they said>`: Outlook for Outlook and for both, Other for anything else. Replace an `- **Email app:**` line that is already there. Never write it in `USER.md`, and never change the `- **Email:**` line, which is the account's address.
- **Gmail or Google:** load pack `email`, call `google_status`, then `google_connect` for each account to add (follow `needs_action` for an existing account). Post its link with `post_update`: `Connecting Google takes one Allow with no Google Cloud project. Sign-in and token renewal go through Google's Workspace extension sign-in service. Open the link in your usual browser, pick your account and click Allow.` Check `google_status` after sign-in. Use skill `google-setup` only when the person says Google blocked the sign-in (for example "Access blocked" or "your admin hasn't allowed this app"), when the same address comes back refused after they said they clicked Allow, or when they ask for their own Google Cloud project. An expired link gets a new link; a Cancel or "not now" is a decline, not a refusal.
- **A selected-local scripted Google miss in the `google-setup` backup:** Only when `bound_model` `source` is `omlx`—the current selected first-chat model is local, which is distinct from the chat's separate Local only setting—and `browser_run_steps` returns `ok: false` with `step`, `says`, and `saw`, but no `message`, `start_at`, or `error`, first do that step and the rest of that file yourself, as `google-setup` says. Only if you cannot finish it yourself, post exactly `I'll finish connecting Google after the remaining setup questions.` and report the stop's `step` and `saw` as `google-setup` says. Keep this existing Email and calendar task open. Retain the script and `step` identifier in its description, plus their answer `both` if they chose both, then use the supported plan reorder to put it in the position immediately before the hand-off task, after the remaining setup steps. When you return to it, first inspect the current Google connection and the actual page; reuse anything already there, create the first project or client only when that inspection shows it is absent, then call `browser_run_steps` again with the same `steps` and `start_at` set to the retained step; if that stops again, do that step and the rest of the file yourself as `google-setup` says. Handle a person decline, an `ok` result with a message, or a `start_at` in place as `google-setup` says. For other stops, follow its agent-handled path and report the `step` and `saw` as it says. An explicit "not now" stays skipped. For an `error`, correct the tool input or report the unavailable tool; never claim Google connected.
- **Outlook:** when your skills list includes `microsoft-setup`, follow it from its step 1. Otherwise post `There's no ready way to connect Outlook. I'll build one after setup. It's on my list.` and add your own task to build it, as skill `connect-tools` says under "No connection exists yet".
- **Both:** Gmail first, as above. Once it is connected or they say "not now" to it, go on as for Outlook. On return from a deferred Google step, first call `microsoft_status` without an `account_id`; if the Outlook account they meant is already connected, do not ask them to connect it again. Otherwise follow the Outlook path.
- **Something else:** follow skill `mail-host-setup` from its step 1.

On "not now" to the question: `Ask me any time to connect your email.` This is CORSIA's own platform sign-in; it creates no agent.
