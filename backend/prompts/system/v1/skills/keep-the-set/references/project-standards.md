# Keep the set: project standards (example)

Copy this into your project's standards and fill each line. The workflow reads it at List the set.

- **Rhythm:** which day and time a run starts, and the events that start an extra one (a new agent, a changed goal).
- **Sources for the set:** where workflows, skills, instruction files, agents and measures are listed.
- **Failures:** where this week's failures are read (corrections, sent-back work, final review findings).
- **Where findings and the change list live.**
- **What the person decides:** the kinds of change that go to them instead of being made.
