# Connect Google

Only the designated CORSIA thread runs this. The person does two things: signs in to Google in the browser you open, and clicks Allow on the sign-in link. You do every other step. Never ask for, type, read, print or paste a password, code, client secret or token.

1. Load pack `email` with `tools_load` and call `google_status`. It lists every account with its `account_id`. If the person means an account listed there, ask which one first when more than one could be meant; if that account shows `needs_action`, follow that instead of this skill. Otherwise call `google_connect` with that `account_id`, post its `reply` verbatim with `post_update` followed by `[Open it in Connected apps](<link>)`, and stop. To connect a new account, including the first, go on to step 2.
2. Post with `post_update`, as one sentence then two bulleted groups, in this order: `To connect Gmail and Calendar, CORSIA creates a private Google project you own, in a browser you can watch. Google will ask to:` then the bullets `Read, send and change your Gmail, and manage your calendar.` `See, edit and delete your Drive, Docs and Sheets files, so you won't have to sign in again later.` then `Two things to expect:` and the bullets `If Google warns the app isn't verified, choose "Advanced", then "Go to CORSIA (unsafe)". It's your own project, so only you can reach it.` `CORSIA may set the project to "In production", because a project left in Testing stops letting CORSIA in after 7 days.` then `Go ahead?` Wait for their yes. On "not now": `Ask me any time to connect your email.`
3. Call `google_connect` with no `client_file`. If it returns a link, a client is already saved: go to step 6. If it says no Google client is saved, go on.
4. Open `https://console.cloud.google.com/projectcreate` with `browser_open` and `show_window: true`, so the person watches it in the shared browser. If the error says to reinstall or update CORSIA, the app's own browser is broken, a gap in CORSIA: tell the person in plain words to reinstall or update CORSIA, report it the way you report any problem with CORSIA, and stop. If it names install commands instead (CORSIA run from source), call `request_host_access` for exactly those commands, stating that the person asked to connect Google and that nothing else is installed or changed. Once approved, run them with host scope, tell the person the browser download takes a few minutes, then call `browser_open` again. If access is refused, give the person those commands to run in Terminal and wait until they say it finished.
5. In the shared browser from step 4: a sign-in, password, 2-Step or passkey page belongs to the person: follow `.corsia/skills/conductor-bootstrap/references/browser-person-steps.md` B. A terms page or a captcha: follow A of that file. Once they are past it, take over in that window. `browser_run_steps` runs a step file CORSIA ships and stops at the first step it can't finish, naming it with its `says`. If the result says the person declined, follow its message and stop. If an `ok` result carries a message, hand the page to the person as `browser-person-steps.md` says, then continue the skill without calling the file again. Otherwise, if it carries `start_at`, the page is the person's: hand it over as `browser-person-steps.md` says, then call again with the same `steps` and that `start_at`. On any other stop, do that step and the rest of that file (`.corsia/skills/google-setup/steps/<name>.json`; each step's `says` is what to do) yourself, and report the stop's `step` and `saw` the way you report any problem with CORSIA.
   a. If the console already has a project named `CORSIA`, select it; otherwise run `steps: "google-setup/console-project"` to create it. After you submit it, Google can briefly alternate between its dashboard and a creation error while the project provisions. Do not revisit `projectcreate` or submit Create again: wait for the project selector to show `CORSIA` as the current project, then continue. If it does not appear after about 5 minutes, first check whether the selector lists `CORSIA`: select it if it does; otherwise ask the person to complete only the project-creation step in the page already open. Never make a second project or client. Once the selector shows `CORSIA` as the current project, run `steps: "google-setup/console-apis"` to enable the five APIs.
   b. Open `https://console.cloud.google.com/auth/branding`: user type Internal when Google offers it (only a project inside a work organization gets it), otherwise External; app name `CORSIA`, the signed-in address as both the support and the developer email, then Save.
   c. Skip this if you chose Internal. Open `https://console.cloud.google.com/auth/audience`, press Publish app and confirm. Read the page again; go on only when it says In production. If you can't press it, ask the person to press Publish there and tell you when it says In production.
   d. Run `steps: "google-setup/console-client"`. It creates the Desktop client `CORSIA`, downloads its JSON and reloads to close the dialog that shows the client secret. If it stops at `download-json` or later, the open dialog shows the client secret, so take no snapshot or screenshot of it: ask the person to press Download JSON. Read the client ID from the Clients list. The file is `~/Downloads/client_secret_<client ID>.json`; never open it.
   If Google says their organization doesn't allow creating projects or this app, post that in plain words, add one sentence they can send their admin, and stop: create no client and try no other route. If you can't finish a step yourself, ask the person to do only that step, at the page you have open. Never hand them the whole list.
6. Call `google_connect` with `client_file` set to that path as is (skip this call if step 3 already gave a link). It reads the file itself, so never list or check Downloads first and never request host access for it. If it says the file isn't a client file, ask the person where their browser saved `client_secret_<client ID>.json` and pass that path. Post the link in chat, never with `browser_open`: it opens in the person's own default browser. Post: `Open this link. It opens in your usual browser: pick the Google account you used for the project (sign in there if asked), and click Allow.` With External, add `When Google says the app isn't verified, choose Advanced, then Go to CORSIA (unsafe).`
7. When they say it's done, call `google_status` and post `Connected as <address>. If that's the wrong account, say so and I'll switch it.` If it still says not connected, post what it says.
