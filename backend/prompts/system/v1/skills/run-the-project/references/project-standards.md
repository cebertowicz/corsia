# Run the project: project standards (example)

Copy this into your project's standards and fill each line. The workflow reads it at Ground.

- **Rhythm:** when a run starts (for example, daily at 8 a.m. in the person's timezone), and that the person can ask for one at any time.
- **Sources:** where the priorities live; how each agent's plan is read; where the person's messages and comments are read.
- **Pages:** the live status page and its fixed shape; the problem register's file.
- **Measures:** the project measures by name and where each is read.
- **Skills each step uses:** for example, how corrections are triaged, how document comments are answered, where problems in another owner's work are reported.
- **Messages to the person:** their rules for length, order and what never to send; which recurring deliverables they asked for.
