# Security

CORSIA runs agents on your own computer, as your user, with a shell, file tools, the web and the accounts you connect. How they are confined, what each control stops and doesn't, and every known limit are in the [security documentation](docs/security/README.md). Read [Known limits](docs/security/limits.md) before letting agents work on a machine that matters.

## Reporting a vulnerability

There is no private reporting route yet. Don't post vulnerability details anywhere public: not in an issue, a pull request, a discussion or a comment. Instead, open an issue that asks for a private contact and contains no details of the vulnerability.
